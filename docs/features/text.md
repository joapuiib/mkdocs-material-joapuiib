# Text

> Referència: [:lucide-external-link: Formatting &mdash; MaterialX](https://jaywhj.github.io/mkdocs-materialx/reference/formatting.html)

## Estils de classe de text

Cada tipus d'[admonició](admonitions.md) té una classe homònima que pinta el text del mateix color
que l'admonició. Així, el text destacat dins d'un paràgraf manté la coherència visual amb les
admonicions del document.

Per aplicar-la, s'envolta el text entre claudàtors i s'afig la classe amb la sintaxi d'atributs.
La classe només canvia el color: la icona de cada exemple és la mateixa que la de l'admonició,
però s'ha d'escriure explícitament.
